Qué se guarda y dónde

La aplicación guarda las citas, pacientes, notas, vacunas, seguimientos y personalización que registres en el almacenamiento local de este navegador. Los cambios guardados se conservan al recargar y entre visitas, hasta que los elimines o el navegador borre los datos del sitio. Un formulario sin guardar puede perderse si cierras o abandonas la página.

La demo no tiene cuentas ni una base de datos compartida entre dispositivos. Cualquier persona que utilice el mismo perfil de navegador puede acceder a lo que hayas guardado; no hay contraseña ni separación entre usuarios. Las pestañas del mismo sitio comparten ese almacenamiento.

Los formularios no envían esos registros a un servidor de CercaVet. No hay analítica ni publicidad incorporadas en la aplicación. Al abrir la web, el proveedor de alojamiento recibe las solicitudes necesarias para servirla, que pueden incluir dirección IP y datos técnicos del navegador. Esto es distinto del almacenamiento local de los formularios.

Copiar un mensaje solo lo lleva al portapapeles. Registrar un contacto o una respuesta es una simulación: no envía WhatsApp ni correo. Exportar datos o descargar un resumen crea un archivo en tu dispositivo; tú decides si lo compartes.

Cómo eliminar tus datos de prueba

Para borrar todo, elimina los datos de este sitio desde la configuración de privacidad de tu navegador. Se eliminarán los registros y la identidad guardados en ese perfil; la próxima apertura de la demo mostrará ejemplos nuevos.

Dentro de Identidad de la clínica → Restaurar datos de ejemplo puedes reiniciar pacientes, citas, consultas, vacunas y seguimientos. Esta opción conserva el nombre, logo y contacto configurados: no equivale a borrar todos los datos del sitio.

Si exportaste archivos, esos archivos permanecen en tu dispositivo y debes eliminarlos por separado. No hay una copia remota ni una función para restaurar una exportación en esta demo.

Qué incluye la prueba gratuita

  • Explorar el recorrido cita → consulta → seguimiento simulado → nueva reserva.
  • Probar vacunas, próximas dosis y la identidad visual de una clínica con información ficticia.
  • Sin suscripción, cobro ni compromiso de contratación por abrir o probar la demo.

Esta es una demostración para evaluar la experiencia. No está preparada para operar una clínica con datos reales: faltan accesos, permisos, respaldo y servicios conectados. Las fechas y notas de ejemplo no son recomendaciones clínicas.

Una implantación se define y presupuesta por separado según equipo, datos, integraciones y soporte. No hay un precio cerrado publicado ni contratación o pago dentro de esta web. Esta explicación describe el funcionamiento de la demo; no constituye un contrato de servicio.
